# Games

Every now and then I enter a game jam: a weekend (or a week) to make a whole
game around a theme. These are the ones that made it out the door. They're all
built in Unity and published on [my itch.io page](https://danish-gamedev.itch.io).

- **Game Dev Loop** (GMTK Game Jam 2025): my first ever jam, about getting
  stuck changing genres every time a deadline gets close.
- **Rolling in Dough** (Brackeys Game Jam 2025.2): tower defence where a cat
  protects its biscuits from dogs. Made with a team; I wrote the code.
- **The Feed** (Pakistan Game Jam): drag and drop news articles to push the
  nation's message.

All three play in the browser on itch.io. Open a game's folder and hit Play, or
type `run the-feed` (or any game's name) in the terminal.
