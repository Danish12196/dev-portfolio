# The Feed

A small drag and drop game about media control. Articles come in, you tag them,
and you decide what gets boosted, approved or quietly rejected.

I made it in a bit of a rush, as always, so I could take part in the Pakistan
Game Jam.

## Controls

- **Right mouse** tags an article.
- **Left mouse** drags articles to Boost, Approve or Reject.
