# Rolling in Dough

A tower defence game where you play as a cat, baking biscuits and defending them
from a steady stream of dogs.

We made it as a team for the Brackeys Game Jam 2025.2 and it's published on my
teammate's itch.io page, mckay makes games. I wrote the code. It plays in the
browser there and there's a Windows download too.
