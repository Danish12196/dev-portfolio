# MAAI901 Deep Learning for Visual Data

The computer vision subject of my master's (Autumn 2026): CNNs, vision
transformers, self-supervised pre-training, and generative models such as
autoencoders.

- **Breaking camouflage**: how well ViT, ConvNeXt, CLIP and DINOv2 classify
  camouflaged animals in COD10K (Assessment 2, Applied Vision Transformer Report).
- **Autoencoders**: an interactive, scrollable presentation on autoencoders and
  VAEs, with small models running live in the browser.
